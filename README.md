# 🔬 Clasificador Cuántico de Riesgo Microbiológico (VQC)

Aplicación web de **Quantum Machine Learning (IBM Qiskit)** diseñada para laboratorios de control de calidad (aguas, industria agroalimentaria y farmacéutica). Evalúa parámetros físico-químicos en recepción para priorizar cultivos microbiológicos urgentes antes de la fase de incubación.

🔗 **Prueba la aplicación en vivo aquí:** https://clasificador-microbiologico-vqc.streamlit.app/

## 🧪 Funcionalidades para Laboratorio
* **Triaje Inteligente (VQC):** Entrelaza temperatura de transporte, pH, turbidez y horas en tránsito mediante un circuito variacional cuántico (`ZZFeatureMap` + `RealAmplitudes`) para detectar combinaciones de riesgo no lineales.
* **3 Modos Operativos:** Análisis de muestras de referencia, ajuste manual con deslizadores de laboratorio y procesamiento masivo en lote mediante archivos **CSV / Excel** con plantilla descargable.
* **Validación en Hardware Cuántico Real (IBM Quantum):** Preparado para ejecutar pruebas piloto sobre procesadores cuánticos físicos (QPU).
